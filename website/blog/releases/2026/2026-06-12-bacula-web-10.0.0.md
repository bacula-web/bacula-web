I'm pleased to announce that Bacula-Web 10.0.0 release is now available

<!-- truncate -->

## Release Highlights

This major release includes dependency upgrades to address multiple CVEs affecting twig/twig and symfony/cache.

* symfony/cache
  * CVE-2026-45073
* twig/twig
  * CVE-2026-48808
  * CVE-2026-48805
  * CVE-2026-46636
  * CVE-2026-48806
  * CVE-2026-48807
  * CVE-2026-46640
  * CVE-2026-46628
  * CVE-2026-46633
  * CVE-2026-47730
  * CVE-2026-46627
  * CVE-2026-46635
  * CVE-2026-46638
  * CVE-2026-24425
  * CVE-2026-47732
  * CVE-2026-46634

Since twig/twig 3.20.0 requires PHP 8.1.0 or higher, and this project follows semantic versioning, these dependency updates require a major release.

See [v9.9.5 to v10.0.0](https://github.com/bacula-web/bacula-web/compare/v9.9.5...v10.0.0) for all changes details.
