I'm pleased to announce that Bacula-Web 10.0.2 release is now available

<!-- truncate -->

## Release Highlights

This is a security and bugfix release.

- Docker image - bump PHP to 8.5.12 for PHP2Shell (CVE-2026-109618, CVE-2026-109619) (#330)
- Fix unused custom database port (see [#323](https://github.com/bacula-web/bacula-web/issues/323))

I strongly recommend to update your PHP version as soon as possible (see [announcement on php.net](https://www.php.net/archive/2026.php#2026-10-21-5)) 

See [v10.0.1 to v10.0.2](https://github.com/bacula-web/bacula-web/compare/v10.0.1...v10.0.2) for all changes details.

## Release notes

Check the [release notes](https://github.com/bacula-web/bacula-web/releases/tag/v10.0.2) on GitHub.

:::tip
As usual, I strongly encourage everyone to upgrade to the latest release.
:::

Enjoy!
