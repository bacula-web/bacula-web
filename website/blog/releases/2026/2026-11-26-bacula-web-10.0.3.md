I'm pleased to announce that Bacula-Web 10.0.3 release is now available

<!-- truncate -->

## Release Highlights

This is a security and bugfix release.

- Bump PHP to 8.5.13 in the Docker image to address latest PHP security vulnerabilities (see [PHP annoucment](https://www.php.net/archive/2026.php#2026-11-19-4))

I strongly recommend to update your PHP version as soon as possible. 

See [v10.0.2 to v10.0.3](https://github.com/bacula-web/bacula-web/compare/v10.0.2...v10.0.3) for all changes details.

## Release notes

Check the [release notes](https://github.com/bacula-web/bacula-web/releases/tag/v10.0.3) on GitHub.

:::tip
As usual, I strongly encourage everyone to upgrade to the latest release.
:::

Enjoy!
