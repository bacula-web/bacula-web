## More infos

::::warning[Web server root has changed since [v8.6.0](https://github.com/bacula-web/bacula-web/releases/tag/v8.6.0)]

As of [release v8.6.0](https://github.com/bacula-web/bacula-web/releases/tag/v8.6.0),
your web server root directory must point to the `public` directory (available at the root)

**For example**

`/var/www/hmlt/bacula-web/public`

> If you are using a different location than /var/www/html/bacula-web, please adjust based on your web server configuration.

::::

::::danger[security vulnerabilities]

Older versions of Bacula-Web have known security vulnerabilities. For the safest and most reliable experience,
use the [latest stable version](https://github.com/bacula-web/bacula-web/releases/latest) with all recent fixes and improvements.

::::

### Docker images

Latest Bacula-Web Docker images (for platform `linux/amd64` and `linux/arm64`) are available at [Docker Hub](https://hub.docker.com/r/baculaweb/bacula-web)

> Bacula-Web official Docker images are available since [release v8.7.0](https://github.com/bacula-web/bacula-web/releases/tag/v8.7.0).
