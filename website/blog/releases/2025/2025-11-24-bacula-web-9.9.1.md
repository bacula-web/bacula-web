I'm pleased to announce that Bacula-Web 9.9.1 release is now available

<!-- truncate -->

## Release Highlights

- Fixed an issue with session cookie secure attribute while using HTTP (not HTTPS)
- Updated instructions to verify signature of pre-built archive (documentation).
- Updated instructions to use Bacula-Web Docker image (documentation).
- Updated and fixed documentation (still a lot to do/fix, work in progress)
- Moved [website and documentation git repository](https://github.com/bacula-web/www.bacula-web.org) content into [main git repo](https://github.com/bacula-web/bacula-web)
  A blog post will be published later to give further details about this change
- and much more fixes and improvements ...

See [v9.9.0 to v9.9.1](https://github.com/bacula-web/bacula-web/compare/v9.9.0...v9.9.1) for all changes details.

## Release notes

Check the [release notes](https://github.com/bacula-web/bacula-web/releases/tag/v9.9.1) on GitHub.

:::tip
As usual, I strongly encourage everyone to upgrade to the latest release.
