# How to get help

## Introduction

If you encounter any issue while installing, configuring, upgrading, or even using Bacula-Web in your environment, or if you have any other issue or doubts.

## Before creating a new issue

You can get help in several different ways.

- Check for [open issue(s)](https://github.com/bacula-web/bacula-web/issues) or [discussion(s)](https://github.com/bacula-web/bacula-web/discussions) on GitHub
- Create a new [discussion in Bacula-Web project](https://github.com/bacula-web/bacula-web/discussions/new/choose) on GitHub
- Contact me by e-mail at [hello *at* bacula-web *dot* org](mailto:hellop@bacula-web.org)
- Get in touch through the [bacula-users mailing list](https://sourceforge.net/p/bacula/mailman/bacula-users/)
- Check the [FAQ](faq)

## Create a new issue

If the above options didn't help, you can create a [new issue](https://github.com/bacula-web/bacula-web/issues) in the Bacula-Web GitHub project.

::::info
Please read the [reporting issue guideline](../contribute/reporting-issue-guideline.md) before creating a new issue.
::::
