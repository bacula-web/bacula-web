# Community

## Join the Bacula-Web Community!

[**Bacula-Web**](https://www.bacula-web.org/) is not just an open source project. It’s a community-driven open source initiative built with passion.

Released under [**GPL v2 license**](https://raw.githubusercontent.com/bacula-web/bacula-web/master/LICENSE), Bacula-Web project is free software!

Built in spare time. Improved by contributors. Supported by users.

And you can be part of it.

## Why Community matters

Open source is not just about code. **It’s about collaboration.**
Bacula-Web exists and evolves because people care enough to improve it.

Every suggestion shared, every bug reported, every pull request submitted contributes to making the project more stable, more secure, and more useful for everyone.

Unlike proprietary software, open source projects don’t rely on large corporate teams.

All open source projects grow thanks to people who decide to contribute whether by writing code, testing releases, improving translations, or simply sharing feedback.

**Even small contributions can have a huge impact.**

A short bug report today might prevent hours of troubleshooting for someone else tomorrow.

That’s the power of community <i class="fas fa-solid fa-heart"></i>

## How you can contribute

### Use & share feedback

The simplest way to contribute is to use Bacula-Web. Install the latest release, explore its features, test it in your environment and share your experience. Your feedback helps :

- Identify usability improvements
- Detect edge-case bugs
- Prioritize future features

Real-world usage is one of the most valuable contributions.

[**Ready to explore Bacula-Web ?**](/docs/)

### Report issues

Found a bug? Something unclear? Unexpected behavior? Opening a [GitHub issue](https://github.com/bacula-web/bacula-web/compare) helps maintainers understand and fix problems faster.

Clear bug reports save time for everyone and improve overall stability. Even confirming that an issue exists in your environment is helpful.

### Submit code

If you're a developer, you can actively shape the project. You can:

- Submit pull requests
- Improve performance
- Refactor code
- Add new features
- Fix bugs

All contributions are reviewed and discussed openly.

*Please read the [contribution guide](/docs/contribute/reporting-issue-guideline/) before submitting changes.*

### Improve translations

Bacula-Web aims to be accessible worldwide. If you speak another language, you can help expand or improve translations through Transifex.

Keeping translations accurate ensures a better experience for non-English users.

### Improve documentation

Good documentation reduces support requests and improves onboarding.

You can help by:

- Clarifying existing documentation
- Fixing outdated information
- Adding usage examples
- Improving installation guides

Documentation contributions are just as valuable as code.
